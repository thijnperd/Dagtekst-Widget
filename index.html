How does this work?
1
Download Scriptable Install the free Scriptable app on your iPhone or iPad via the App Store. App Store → Scriptable
2
Customize the theme Choose a theme or set colors, font and ornament via the tabs on the left.
3
Export the script Click Export Script above to download the .js file, or copy the code via the Script tab.
4
Paste in Scriptable Open Scriptable on your iPhone → tap + → paste the copied code → save. Then add a Scriptable widget to your home screen and choose this script.
