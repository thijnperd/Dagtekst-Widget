## 🇺🇸 English

### ✨ Features

- 🎨 **Preset themes** — choose from several ready-to-use styles.
- 🌈 **Full color control** — separate settings for light and dark mode.
- 🔤 **Font selection** — over 20 iOS fonts available.
- ✦ **Ornament picker** — decorative characters for the top and date sections.
- 📐 **Size & padding** — adjustable for small, medium, and large widgets.
- 📱 **Live preview** — see results instantly, including a phone simulation.
- 💾 **Export as `.js`** — ready to paste into [Scriptable](https://scriptable.app).

### 🚀 Getting Started

1. **Download Scriptable:** Install the app from the [App Store](https://apps.apple.com/app/scriptable/id1405459188).
2. **Open Builder:** Open `widget-builder.html` in your mobile or desktop browser.
3. **Customize:** Use the tabs to adjust colors, fonts, and ornaments.
4. **Export:** Click **Export Script** — it will download `DagelijkseTekst.js`.
5. **Paste in Scriptable:** Create a new script in the app, paste the code, and name it.
6. **Add Widget:** Long-press your home screen → add a [Scriptable](https://scriptable.app) widget → select your script.

> 💡 **Tip:** See the [Advanced Settings](#️-advanced-settings--geavanceerde-instellingen) section to change the display language of the daily text.

## 🛠️ Technical Details

- **Data Source:** Fetches daily text data via the WOL API from [JW.org](https://www.jw.org).
- **Compatibility:** Automatically supports iOS Light and Dark mode.
- **Widget Sizes:** Works on all three iOS widget sizes (small, medium, large).
- **Requirements:** [Scriptable](https://scriptable.app) app — free on the [App Store](https://apps.apple.com/app/scriptable/id1405459188).
