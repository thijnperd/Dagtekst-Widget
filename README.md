## 🇺🇸 English
A visual widget builder to create a beautiful **Daily Text** widget for your iPhone, fully personalized with custom colors, fonts, and ornaments.
> Built for use with the **Scriptable** app on iOS/iPadOS.
> 
### ✨ Features
 * 🎨 **Preset themes** — choose from several ready-to-use styles.
 * 🌈 **Full color control** — separate settings for light and dark mode.
 * 🔤 **Font selection** — over 20 iOS fonts available.
 * ✦ **Ornament picker** — decorative characters for the top and date sections.
 * 📐 **Size & padding** — adjustable for small, medium, and large widgets.
 * 📱 **Live preview** — see results instantly, including a phone simulation.
 * 💾 **Export as .js** — ready to paste into Scriptable.
### 🚀 Getting Started
 1. **Download Scriptable:** Install the app from the App Store.
 2. **Open Builder:** Open widget-builder.html in your mobile or desktop browser.
 3. **Customize:** Use the tabs to adjust colors, fonts, and ornaments.
 4. **Export:** Click **Export Script**. It will download DagelijkseTekst.js.
 5. **Paste in Scriptable:** Create a new script in the app, paste the code, and name it.
 6. **Add Widget:** Add a Scriptable widget to your home screen and select the script.
